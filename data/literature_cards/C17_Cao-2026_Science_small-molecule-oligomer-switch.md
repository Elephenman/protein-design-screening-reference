## 1. 这篇到底解决什么（一句话与大白话）

**一句话**：让一个全新设计的 65 个氨基酸左右的小蛋白，在里没有金刚烷胺时老老实实当单体、把药加上后高效组装成三聚体——把「加不加这个小分子」变成蛋白聚/散的开关，并让这种「两态都要对」的功能可以用计算设计出来。

拆开说三层：

1. **设计对象不是结合一个靶，而是控制一次组装**。底稿对该文设计对象的记录：小分子（FDA 已批金刚烷胺 amantadine）调控的蛋白同源三聚体（mAIT/dAIT）与异源二聚体/三聚体（AMA10 系列），单体约 65 个氨基酸。
2. **成功判据是「两个态」而不是「一个态」**。它不像 binder 那样只要「按设计的界面结合上」，而是要同时满足：无配体时单体稳定（不成团、不聚），有配体时高效组装（可测的寡聚态变化），而且这个差别要能被小分子可逆地推着走。底稿在曹组方法演进链里就是这么归类的：判据从「单态结构像不像」变成「两个态都要自洽 + 态间自由能差符号正确」，并点名本文的形态是「无配体单体稳定 / 有配体高效组装」。
3. **它要解决的是可用性**：用途记为蛋白定位、无膜细胞器（condensate）形成、基因表达调控，直到小鼠口服给药后激活肝转基因——即把「吃药控制蛋白组装」做成一个能在动物里走通的器件，而不是只拿一个结合常数。

在曹组时间线里的位置（底稿原话）：他组最「物理+深度学习混合」的成果，**把配体结合界面复用（对称性匹配）当作漏斗的第一道闸**，使「配体诱导组装」这类此前不可设计的目标从约 4% 提到 50%+ 的投测命中（此比例本身是二级来源，见第 4 节）。

## 2. 遇到的难点，以及遇到问题时他们做了什么（依据登记底稿，不含正文级细节）

> 本节只能写到底稿记录到的层面。**本文未获正文**，因此「现象/证据」列凡是数字都带 ⛔/⚠️ 标记；作者自述的取舍只到 `sources/cao.md` 记到的粒度。

1. **第一代体系几乎全军覆没——单体自己就想聚，配体说了不算。**
   现象/证据（⛔二级来源，西湖大学官方稿中文转载，未在论文正文核实）：在最早的设计（单金刚烷胺诱导三聚体 mAIT）中，「所设计的 24 个蛋白质中仅有一个蛋白展现微弱的『遥控组队信号』」→ **1/24 = 4.2%**。
   他们做了什么：**没有在 mAIT 上继续调参，而是换掉设计范式**——底稿记为「对接-结合同步优化」：先用对称性匹配把「配体结合界面」当成第一道闸（RifGen 生成对称的 "rotamer interaction field" 来评估蛋白-配体结合），再用蒙特卡洛片段装配把三螺旋束单体在对称约束下拼成同源三聚体，**同时**优化蛋白-蛋白（RPX 哈希）与蛋白-配体（RIF 打分）两路相互作用；序列由 Rosetta + ProteinMPNN 出。改造后走 dAIT 路线，底稿记为「在 48 个候选蛋白中，有 27 个『杀出重围』」→ **27/48 = 56.3%**。
   应对后仍留下的代价：两代分母都是几十（24 与 48），「杀出重围」的准入判据与阈值**未从正文核实**（底稿第 418 行直接标 ⛔阈值未核实）；因此「4%→56%」目前是**口径待核的二级来源数字**，不能当命中率引用。

2. **设计对象没有「目标构象」可对齐——判据必须写成两态不等式，而不是单态打分。**
   现象/证据：底稿在曹组方法演进链里把本文归入「没有目标构象的功能型设计（开关/传感/光/小分子）」这一支（C03→C15→**C17**→C21），并写明这一支的判据形态变化：从「单态结构像不像」变成「两个态都要自洽 + 态间自由能差符号正确」，本文的具体形态是「无配体单体稳定 / 有配体高效组装」。
   他们做了什么：正因为常规扩散模型是为「单一稳态」优化的，底稿记录他们没有直接用为静态结构训练的生成路线，而是**回到物理建模 + 自研/混合生成**（RIFGen + 蒙特卡洛片段装配 + Rosetta/ProteinMPNN）；需要异源组装时另辟一条路——用 RFdiffusion 生成连接螺旋把同源三聚体的两个亚基融合，再用 ProteinMPNN 做正负电荷设计，得到异源二聚体 AMA10。
   应对后仍留下的代价：两态判据的**数值形式与阈值本文底稿全无记录**（第 3 节相应格写「未从正文核实」）；「态间自由能差符号正确」在他们那里是设计目标还是事后判据，未获正文无法判定 → **本文未解决（对我们是可核实的缺口，不是作者的失败）**。

3. **「组装对了没有」用便宜手段判不了，末端测量又贵又慢。**
   现象/证据：底稿记录的实验链是 E. coli 表达 + SEC、SEC-MALS、ITC/BLI、晶体学（1.5 Å）、流式与报告基因、小鼠体内；结构精度只有转述级数字——dAIT17「1.5 Å 分辨率晶体结构」与设计模型「Cα 原子 RMSD 仅 0.67 Å」（⚠️来自丁香园/163 报道转述正文）。
   他们做了什么：把「贵但唯一判得了价态与几何」的测量（SEC-MALS、晶体学）留在漏斗末端做确认，同时用功能读数（流式/报告基因、小鼠口服激活肝转基因）证明开关在细胞与动物里真的能切换，而不只在试管里聚。
   应对后仍留下的代价：这套末端测量通量只有几十，**分母天生小**；可溶性/表达量在漏斗里淘汰了多少，底稿未记录 → 无法还原完整漏斗递减。

4. **计算侧完全没有「筛子考卷」——所有淘汰发生在下单之前，但门槛数字进不了公开可核层。**
   现象/证据：`sources/cao.md` 第 275 行对本文计算筛选器的记录止于「见上（RIF/RPX 双打分 + 对称性约束）；⛔具体阈值数字未从正文核实」；第 471 行把它列进「未能核实的问题清单」第 1 条，并写明能改变结论的证据是什么：「**能改变结论的证据**：Science 正文或 SI 中的表（design list + SEC/ITC 结果）。当前不能把这些数字列为『论文级』」。
   他们做了什么：**本文未解决**（底稿层面看不到任何回溯性判据评估或阈值-结局配对的描述；这与曹组其他论文不同——Bennett 2023 [B09] 那种「用历史湿实验给筛子打分」的做法，在本文底稿里没有任何记录）。
   应对后仍留下的代价：读者无法复算、无法把这套判据迁移到别的配体-蛋白对，只能接受「换了范式以后投测命中变高」这个转述级结论。

## 3. 方法与工作流程（每步：输入 → 操作 → 判据/阈值 → 输出规模）

**⚠️ 降级卡的硬约束**：本节只有「操作序列与判据形态」来自登记底稿；**所有阈值数字一律写 未记录（未获正文）**，不编造。底稿第 275 行对本文筛选器的原样记录是：⛔**具体阈值数字未从正文核实**。

### 用了哪些方法（工具箱，按底稿记录）

- **配体-结合界面侧**：RifGen —— 底稿描述为「RifGen 生成对称 rotamer interaction field 评估蛋白-配体结合」，即把 rotamer interaction field（RIF）在对称操作下铺开，用配体（金刚烷胺 amantadine）与设计的对称界面上的结合能打分。
- **组装体装配侧**：**蒙特卡洛片段装配**，把三螺旋束单体在对称约束下拼成同源三聚体；关键动作是**同步优化**蛋白-蛋白（RPX 哈希）与蛋白-配体（RIF 打分）两路相互作用，而不是先设计折叠体再事后检查配体位点。
- **序列侧**：Rosetta + ProteinMPNN。
- **异源体系**：RFdiffusion 生成连接螺旋（把同源三聚体的两个亚基融合成一条链）+ ProteinMPNN 的正负电荷设计 → 得到 AMA10 系列异源二聚体。
- **实验侧**：E. coli 表达 + SEC、SEC-MALS、ITC/BLI、晶体学（1.5 Å）、流式与报告基因、小鼠体内口服给药。
- **MD / QM**：底稿第 276 行记 ⚠️摘要级未见 MD/QM 证据；CSV 的 是否用MD / 是否用QM 两列对 C17 都填 未记录。→ 本卡**不得**声称本文用了或没用自由能模拟，只能说未获正文、无从判定。

## 6. 结论——我们读出了什么（以下为推断，非作者原文）

1. **这篇的「功能」被拆成了三条可独立失败的判据，而不是一条分数**：① 无配体时必须是单体（不散自聚）；② 有配体时必须高效到设计价态（聚得起、聚得对）；③ 撤掉配体能回去（可逆）。三件事分别绑不同测量（SEC 单体比例 / SEC-MALS 价态 / 加药-洗药循环或剂量-反应），所以「组装 vs 不组装」的区分是**按事件分派仪器**，不是按总分排序。→ 对我们：分步化学事件也应各自绑一个能独立失败的读数，而不是把三个事件的证据合成一个 ranking 分数。
2. **命中率的分母是「投测集」，不是「设计库」**。1/24 与 27/48 只覆盖湿实验下单那一层，S1→S3 计算淘汰了多少完全未记录（也可能很大但没报）。→ 对我们：报任何比例都必须当场说明分母是哪一层（召回集 / 计算通过集 / 送测集 / 纯化集），否则跨论文比较就是把不同层级的比值放同一张表——这正是本项目在 C19（16 个/靶）与 C02（10⁵ 设计）之间反复踩到的口径坑。
3. **跃升来自换判据的层级，而不是调阈值**。第一代的问题（单体自己就聚、开关失灵）被归到「蛋白-蛋白与蛋白-配体两路相互作用没被同时优化」，解法是把两路打分并进同一轮蒙特卡洛装配，而不是回去改 RIF 的截断值。→ 与 [B09] 的 Type I/II 分型同构：**先分型，再决定改哪一层**。差别是这篇连分型阈值都没公开，所以它只能证「做法」不能证「效果大小」。
4. **把配体的药理属性当成设计约束前置**（选 FDA 已批的 amantadine，使得体内口服这条应用从一开始就可达）。→ 我们可类比的前置约束只有一类：**产物身份必须可被 LC-MS/MS 唯一判定**；不满足这一判据可能性的候选，应该在召回阶段就出局，而不是等湿实验。
5. **这条线没有「筛子考卷」**。底稿里看不到任何用历史湿实验结局给判据打分的环节（对比 [B09] 的百万级回顾集），所以它对我们最大的用处是**结构性的**（怎么拆事件、怎么把两态写成规格），而不是校准性的（没有可借用的通过率/阈值）。把握度：高（就「底稿未见」而言）；**低**（就「正文里真的没有」而言——正文未获，可能有 SI 表未被看到）。

## 8. 迁移判断：哪些能搬、哪些不能搬（「功能拆成可判子事件」的写法能不能搬到分步化学事件）

先回答核心问题：**能搬的是「把功能写成两态不等式 + 每个子事件绑一个能独立失败的读数 + 分母必须点名」这三件写法层面的事；不能搬的是它的全部数值（RIF/RPX 打分、4.2%/56.3%、0.67 Å）**。本库迁移边界（§8） 已明禁把 binder/开关类阈值当酶活闸口，本卡按此执行。

**可迁移（具体怎么用）**

1. **「两态不等式」直接对应分步化学事件的写法升级**。他们的规格不是「分数高」，而是符号关系：无配体态 A（单体）须优于配体态 A（寡聚）的反面，即「无配体单体稳定 / 有配体高效组装」。搬到我们：把每个化学事件也写成**成对条件**而非单点判据——
   - 第一步（游离底物起始）：加底物/对照前后，第一步通量应**被压制**；只有背景时无产物；
   - 第二步（中间体生成）：第二步中间体应**随条件单调出现**，且能被同一读数区分「没做」与「做得少」；
   - S2（第二底物 vs 副反应竞争）：环化与二掺是**竞争比**，判据应是两产物之比 >1 或 <1 的符号，而不是绝对产量。
   写法上唯一要抄的是：**每条判据都必须自带「该发生 / 不该发生」两个方向**，且各绑一个读数；否则它只是排序分数，不能证伪。
2. **「组装 vs 不组装」的区分方式是分派仪器，不是加权重**。他们用 SEC（单体比例）+ SEC-MALS（价态）+ 晶体学（几何）分别判三件事。搬到我们：一个候选的「卡在哪一步」必须由**不同的测量**分别承担——LC-MS/MS 产物身份定 S1/S2 是否发生，定量同位素内标定通量比，失活对照（催化残基突变）定「不是非酶背景」；把这三件事合并成一个综合分会重演他们的第一代错误（结构可能对、功能不可控）。
3. **状态必须允许 UNKNOWN 与 METHOD_FAIL**。他们的漏斗里「未通过」与「没测到」不可区分（新闻口径只有「杀出重围」）。我们的登记必须把「判据不适用/仪器没分辨出来」写成独立状态，否则失败归因会被静默并入阴性。
4. **「第一道闸是位点/界面能否复用」的顺序可搬**。他们先问「这个配体界面能否被对称复用」，再折叠装。类比到我们：先问「这个口袋能否同时容纳底物与催化几何（保守供体/金属位/Pfam 域组合）」作为召回闸门，再谈排序——顺序本身就是可搬的设计知识（本项目第 11/13 轮的 B_FOLD/B_SITE 双轴正是这个形状，只是他们的阈值不可借用）。
5. **「失败分型驱动换范式」的决策规则**。mAIT→dAIT 的跃迁不是调阈值而是把两路相互作用并进同一轮优化。我们对应：若某轮失败集中在某一个子事件（例如 S1 有、S2 全无），下一轮改的是**那一层的构造方式**（环化竞争的空间约束），而不是全局放宽打分截断。
6. **命中率报告格式**：任何比例必须写成 分子/分母·分母所在层·判据定义 三件套（本卡第 4 节即按此登记他们的数字）。这是这篇给我们的最可执行的一条纪律。

**不可迁移（为什么不能照搬）**

1. **RIF / RPX / 对称性匹配分数不是酶活判据**。它们衡量「静态结合界面对不对」；分步化学事件是**共价化学事件**（亲核攻击、焦磷酸键形成、环化 vs 二掺竞争），需要过渡态几何与能垒，界面几何既非充分也非必要。把它们的任何一个阈值写进我们的闸口就是违规引用（本库判据 §2）。
2. **4.2% 与 56.3% 不能当我们的成功概率或校准锚**。分母是 24 与 48 的两个**不同投测集**，上游计算淘汰量未记录，且数字是 ⛔二级来源；把它们折算成「酶设计命中率预期」属于凭空造数，本项目禁止（也不许反向引用成「功能设计只能到 5%」这类结论）。
3. **SEC-MALS/晶体学式的价态-几何判读判不了催化**。他们「对不对」= 有没有按设计价态聚集；我们「对不对」= 有没有按设计化学键连接产物。量纲不同，不能相互标定，也不能拿他们的 1.5 Å / 0.67 Å 当我们的结构通过线。
4. **通量口径不可比**。他们没有展示库级通量（末端测量昂贵，几十级），本项目同样只有极小投测（一轮最多四个构建体），因此与酵母展示 / 百万液滴类论文（如 C23 的 sdDE-FACS）的「漏斗宽度」根本不在同一轴上——跨类比命中率必须先把分母层级对齐，本卡只能给定性对齐结论。
5. **本文无 MD/QM 证据（且无正文可查）**，因此**不能**被引为「功能设计该不该上自由能模拟」的任何一方的支持证据；我们那部分判断要另找参照（本项目自有 MD/QM 单价与判据记录，见本库侧文档与 B09/K 系列卡）。
6. **他们的「可逆开关」靠配体浓度，我们的三步化学事件不可逆**。别指望把「加药-洗药循环」式的可逆性判据搬到共价产物上；可类比的部分只有「条件对称性」（有/无底物两态），且必须重新用产物化学定义读数。
