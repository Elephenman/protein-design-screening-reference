# 写卡代理的操作规程（每个代理先读这份，再读样板卡 B09）

## 节奏（上一批有代理读完三篇全文就断了，什么都没写下——不许再发生）

- **一个代理只写一张卡**。
- 读全文用 Grep 定位（Abstract / Results / Methods / Figure legend / Discussion 的关键句），拿到原句就**立刻落盘**：
  先 Write 一个十节齐全的骨架，再逐节 Edit 填内容。任何时候中断，磁盘上都有一张能看的卡。
- 不许"先读完所有内容再动笔"。

## 你要交付什么

分给你的每个 CSV 行写一张精读卡：`data/literature_cards/<编号 slug>_<短横 slug>.md`。
**文件名 slug 规则**：编号里的非字母数字（空格、分号）全部换成连字符，例如编号 `B06; C02` → 文件名必须叫
`B06-C02_xxxx.md`（门禁按 `<slug>_.md` 找卡，写成 `B06; C02_x.md` 会被判"无卡片文件"）。
内容重点是三块：**用了什么方法**、**工作流程一步步怎么走**、**遇到问题时他们做了什么**。其余节按样板写。

## 硬规则（违反就是返工，门禁会红）

1. 小节必须是 `## 0.` 到 `## 9.` 十个，编号连续、顺序固定，标题分别含：
   元信息 / 解决什么(或一句话) / 难点 / 方法+工作流 / 台账 / 作者 / 我们 / 局限 / 迁移 / 溯源。
2. **引句 = 逐字**。卡里凡是用直双引号 `"..."` 包住、纯英文、≥20 字符、≥12 个字母的片段，门禁就当作"原文逐字引用"，必须在**该编号登记的每一份本地全文**里原样命中。所以：
   - 只引你正在读的这份全文里真实存在的句子；复制粘贴，不要凭记忆重写。
   - 不要跨句拼接（原文两句之间夹着参考文献编号 `21`、脚注、`Fig. 1` 之类时，拆成两条引句）。
   - 不要用省略号开头/结尾冒充引句。
   - 术语、状态名（UNKNOWN、METHOD_FAIL 这类）不要加英文引号。
   - `未记录`、`摘要级` 等中文叙述里的引号不受限（含中日韩字符就不核验）。
   - 有全文的卡至少 8 条引句；不够就去找更多关键句（Methods、图注、Results 段）。
3. 工作流程表：每步写 `输入 → 操作 → 判据/阈值 → 输出规模`，步骤 ≥3。阈值必须是原文里的数字（没有就写"原文未给阈值"）。
4. 难点节：每条 = 难点 → 现象/证据（尽量原句）→ **他们做了什么**（改协议/换指标/加对照/放弃该靶）→ 应对后仍留下的代价。≥2 条。作者没写应对的，明写"本文未解决"。
5. 数字台账：每行 `数值 · 含义 · 出处`。数字必须能在全文里搜到；近似值保留原文的 `~`。
6. 结论分两节：第 5 节只写作者说的；第 6 节写我们推断的，开头标"以下为推断"。
7. 第 8 节迁移判断：可迁移的写怎么用；不可迁移的写为什么不能照搬。**不许**把 binder 的 pAE/ipTM 阈值、适配体 FEP 命中率、展示库通量当成 UAA 酶活的判据或成功概率。不许编造"某法对 UAA 成功率 X%"。
8. 第 9 节末尾必须有 CSV 回填块（14 个键一个不能少，值不能为空，没有就写 `未记录（原因）`，值里不能换行）：

```
<!--CSV回填
work_type=…

```

## 行是 DEGRADED（没有本地全文）时
只准用登记底稿（`sources/*.md` 的对应卡片段落）与摘要级信息写卡：第 0 节证据级别写"摘要级/二级来源/未获正文"，第 2 节写明"作者自述部分未获正文，无法核验"，第 3、4 节不许编造阈值与步骤细节，引句 ≥2 条且必须能在登记底稿里命中。**卡内不许出现"全文级"字样。**

- **每张卡必须在 §9 溯源里写一行**：`引句底稿: data/literature_cards/fulltext/<编号>_<PMC号>_text.txt`（或降级卡的 `sources/xxx.md`）。门禁只拿这一份文件逐字比对全部引句；同一篇论文可能有 Europe PMC 与 NCBI 两份抽取版本，句子中间夹的参考文献编号不一样，所以必须声明你实际照着写的那一份。**不写这行 = 卡片直接 FAIL。**

## 非论文行（价目表／公司自述新闻／本报告推算）写"取证卡"——已获批的口径

总表里约 40 行根本不是论文：厂商挂价、核心设施收费页、公司新闻稿、以及本报告自己做的推算。
这些行**仍然出十节卡**（CSV 回填与门禁不改），但内容换成取证口径，样板见
`K02_twist-gene-synthesis-price.md`、`K03_gene-synthesis-2023-historical-price.md`、`K04_genscript-opools-price.md`：

- §0 元信息：明写"条目类型=价目表／公司自述（非论文）"，证据级别写 二级来源／题录级／未获正文。
- §1：这条数字回答什么问题（一句话）。
- §2 标题必须含"难点"二字（门禁按关键词扫标题）。写**这条来源本身的坑 + 我们取证时做了什么应对**：
  起价 vs 成交价、分母不同（按碱基 / 按池 / 按小时）、快照过期、二手转引、无第三方审计、不含下游成本。
  作者/来源方没解决的明写"本文未解决"。
- §3 标题必须含"方法"或"工作流"。写**取证流程**：定位来源 → 抄口径 → 与其它条目对照 → 落到哪个下游推算。
  表格 ≥3 步，每步仍写 输入→操作→判据/阈值→输出规模。
- §4 数字台账：数值 · 含义 · 出处（推算值必须标"本报告推算"）。
- §5 标题必须含"作者"——写成"## 5. 作者／来源方说了什么"，只陈述来源方给了什么、没给什么。
- §6 以"以下为推断"开头；§7 局限；§8 迁移（可用/不可用，禁止把价目当判据门槛）。
- §9 溯源 + `引句底稿: sources/cost-benchmarks.md`（或对应 sources 文件）+ 14 键 CSV 回填块。
- 引句：≥2 条，必须逐字命中那份 sources 记录。先跑这条取素材：
  `python -c "import re,sys;sys.path.insert(0,'scripts');from litcards_text import norm;t=norm(open('sources/cost-benchmarks.md',encoding='utf-8').read());[print(repr(s[:140])) for s in dict.fromkeys(x.strip(' ,;:.') for x in re.findall(r\"[A-Za-z0-9][A-Za-z0-9 ,;:.%\\$()/''\\-~<>=+]{19,}\",t)) if '*' not in s and sum(c.isalpha() for c in s)>=12]"`
  **注意**：带 markdown 强调 `**` 的句子会被门禁剥掉星号而源文本仍带星号 → 不要选含 `**` 的片段。
- 不许做的事：把这些行写成"论文的方法与结论"；不许出现"全文级"；不许为了凑步骤编造实验流程。
