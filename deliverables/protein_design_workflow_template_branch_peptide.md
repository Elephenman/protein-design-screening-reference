# 分支 C · 肽、大环与小骨架（peptide / macrocycle / miniprotein）

主模板 [protein_design_workflow_template.md](protein_design_workflow_template.md) 的分支参数页。
本分支最容易被误用的地方：**命中率的分母通常是"合成成功且可测"的子集，而不是下单数**，
因为环化产率与化学合成失败会先吃掉一大截（[B15]：27 条合成里 13 条、11 条里 3 条因环化产率不足被剔）。

覆盖的库内证据：环肽 [B15]、螺旋肽结合体 [B12]、靶条件扩散 [B14]、小 β 桶 [B11]、
支撑环 RBL [B34]、肽结合蛋白 [B33]、异手性 D-肽 [C13]、植物肽 FEP [Z05]、
多策略新抗原肽 [Z03]、pMHC 肽设计 [Z04] [Z11] [Z12] [Z15]。

## C.1 本分支的默认路线

```
位点(沟槽/热斑) → 环肽扩散(RFpeptides 类)或靶条件扩散/部分扩散 → 每骨架 4 条序列
  → AfCycDesign 类环状位置编码复折 → 化学合成+环化 → 纯度门槛 → 单一浓度 100 µM 筛
  → K_D 动力学 → 可开发性面板
```

| 项 | 默认阈值 | 证据级别 | 出处 | 不适用/失灵时怎么办 |
|---|---|---|---|---|
| 环肽复折主闸 | iPAE < 0.13（GABARAP）/ < 0.3（MDM2）/ < 0.4（RbtA）；MCL1 正文未给数值 | P0 | [B15] | 逐靶不同＝本体系必须重标（主模板 §H），不许取最松的一档通用 |
| 界面物理项 | ddG < −30（GABARAP、RbtA）或 < −50 kcal/mol（MDM2）、SAP < 35、CMS > 300 Å² | P0 | [B15] | 与 [B12] 的 ddG < −40 是不同体系，不许混成一档 |
| 设计–预测一致性 | r.m.s.d. < 1.5 Å（RbtA）；单体自洽 pLDDT > 0.8 | P0 | [B15] | 达不到就回到簇代表策略（[B15] 335 条未合成、改测 80 簇代表） |
| 每骨架序列数 | 4 条（环肽战役口径）；单体标定用 8 条 | P0 | [B15] [B28] | 送测总数被合成产能锁死，先算合成预算再定序列数 |
| 下单规模 | 每靶 ≤20 条（四靶全部拿到中-高亲和结合体） | P0 | [B15] | 小样本＝命中率区间极宽，报数必须带 n |
| 筛选点 | 单一浓度 100 µM | P0 | [B15] | 只给"结合候选"级别结论，不给 K_D |
| 结构/折叠读数 | 螺旋/桶类：CD 谱 + 95 °C 部分折叠 + 回冷回收三项同时满足 44/102 ≈ 43%；可溶 77/102 ≈ 75% | P0 | [B34] | 只报"可溶"不报"折叠"是本分支最常见的口径缺失 |

## C.2 化学合成与环化：本分支独有的闸口

| 项 | 默认阈值 | 证据级别 | 出处 | 不适用/失灵时怎么办 |
|---|---|---|---|---|
| 环化产率门槛 | 未记录（[B15] 只报淘汰数：27→13、11→3 因环化产率不足） | P5 | [B15] | 自己体系必须先建立产率分布，否则命中率分母失真 |
| 可测子集定义 | 合成品需过纯度/质谱才计入"可测"（[B15] 27 合成 → 14 可测） | P0 | [B15] | 报告时写"分母=可测数"，另附合成失败数 |
| D-肽/非天然体系 | 无法生物表达 → 池合成 + 化学合成，末端收窄到 2 个分子 | P0 | [C13] | 分选群体 140 与 11 是嵌套群体，**不可相加**，也不许相除成成功率 |
| 基因路线的分界 | 需 SSM/展示库的肽类似物受芯片 DNA 长度限制（[B33] 只覆盖 65 aa） | P0 | [B33] | 超过长度上限就退回化学合成，别假设产线能做 |

## C.3 何时用 FEP/MD 优化肽（以及它的真实证据强度）

| 项 | 默认阈值 | 证据级别 | 出处 | 不适用/失灵时怎么办 |
|---|---|---|---|---|
| 位点扫描 | 全位点丙氨酸/去硫酸扫描 → 判"不可动位点" → 只设计 2 条 | P0 | [Z05] | 2/2 方向一致，**n=2 不得当命中率证据**（卡里已写死） |
| 准入判据 | 逐突变 FEP：18.4 ns/次 × 6 副本 × 结合/游离两态 ≈ 220.8 ns/突变；准入 ΔΔG < 0 | P0 | [Z05] | 单点误差棒 ±1.16/±1.34 与效应值同量级时，结论只到"方向层" |
| 疫苗肽框架 | 四道闸门后 6 条中 5 条验证（5/6） | P0 | [Z03] | 分母是闸门后的 6 条，不是 >10⁹ 肽空间；上游通过率未记录 |
| 纯计算读数 | 5 个候选中 3 个判为增强（3/5） | P1 | [Z12] | 这是**计算预测分布**，不是湿实验命中率 |
| MD 训练类 | 48 个体系轨迹用于训练；无 N→M→K 计数 | P1 | [Z15] | 无正文（NO_OA_FULLTEXT），不得引任何数字 |

## C.4 本分支的禁用清单

| 不许做 | 原因 | 证据级别 | 出处 |
|---|---|---|---|
| 把蛋白 binder 的每靶 96 条命中率套到环肽 | 环肽下单被合成/环化产能锁死，分母定义不同 | P0 | [B15] [C13] |

| 把 [B11] 的"约 90% vs 约 30%"当提升倍数引用 | 两个分母都是自选表征子集 | P0 | [B11] |
| 假设 SSM/展示库能覆盖任意长肽 | 芯片 DNA 长度上限 65 aa | P0 | [B33] |
| 用 in silico 通过率承诺湿实验结果 | [B15] 未给统一命中率百分比，也未与库法做同靶平行对照 | P0 | [B15] |
