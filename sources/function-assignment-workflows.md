## 二、金属依赖核酸转移酶（Thg1 / CdnD-E / polymerase / TLP / TENT）特异性能量表

## 三、多证据 → 一个概率：可操作做法与最小校准集

### 3.1 可搬运的框架（ACMG/AMP 的似然比化，是文献里最成熟的"多证据→概率"制度）

✅ **10.1038/gim.2017.210**（Tavtigian et al., Genet Med 2018）【全文，逐句】：
- 把 ACMG 证据等级翻译成**朴素贝叶斯分类器**：`Post_odds = Prior_odds × Π OP_i`（每个证据的 odds of pathogenicity 相乘）；
- 等级之间按**几何/指数标度**：`OP_Su × X = OP_M`，`OP_M × X = OP_St`，…；**唯一最优指数 X = 2.0**（只有 X=2 时才有 7 对致病规则、10 对可能致病规则给出完全相同的 Post_P；其他值最多 1 对）；
- 论文示范表 1 参数：**X=2.0、Prior_P = 0.10、OP_VeryStrong = 350**（→ Strong 175、Moderate 87.5、Supporting 43.75，良性等级取倒数）；
- 概率阈值带：**LP = 0.90–0.99、P > 0.99、LB = 0.001–<0.10、B < 0.001**；
- **BA1（stand-alone benign）被排除**在贝叶斯框架外，因为它是"绝对否定"，与贝叶斯更新不相容——**这条对我们很重要**：闸门体系里可以有一个"一票否决"的化学/结构闸门（例如"受体 5′ 端无三磷酸/无活化路径"），但必须显式声明它不是概率项。

✅ **10.1016/j.ajhg.2025.07.011**（Pew, …, Tavtigian, AJHG 2025）【摘要，逐句】——**相关性证据不能相加**：
- "多路检测与计算工具对**新**变体的（联合）性能从未被确证"；
- 用从 case-control 比值转换为致病比例的**最大似然模型**，单独与联合评估功能实验+计算工具；
- 定义 **ECAR**（exceptionally conserved ancestral residues）：落在 ECAR 的错义突变"不成比例地更可能致病，效应量接近蛋白截短变异"；
- **在 ECAR 以外的位置，功能实验与计算工具的一致预测常常"不满足 ACMG 的相加性假设"**（即两个"独立"证据的 LR 相乘会高估）。
- ⇒ 对我们的启示：**420 ns MD 的口袋统计与金属配位统计高度相关**（同一构象系综的函数），它们的 LR **不可相乘**；必须把它们合并成"一个证据块"，或用经验联合校准（拿一批"MD 通过/不通过 × 实验有/无活性"的联合列联表直接估联合 LR）。

✅ **10.1186/s13073-025-01536-3**（Fortuno et al., Genome Med 2025, TP53 VCEP）【全文】——把 LR 落到"打分制"的操作细节：
- 每个 code 用**点制**映射到证据强度，并给出精确阈值：PS2_VeryStrong ≥8 点 / PS 4–7 / PS_Moderate 2–3 / PS_Supporting 1；PS4 同理（≥8 / 4–7.5 / 2–3.5 / 1–1.5）；
- PP3 的**可执行阈值**：`aGVGD class C65 + BayesDel ≥ 0.16` → Moderate；`C25–C55 + BayesDel ≥ 0.16` → 标准 PP3；`SpliceAI ≥ 0.2` → 剪接类 PP3；
- PM2_Supporting：AF < **0.00003（0.003%）**；BA1：**FAF ≥ 0.001**；且"稀有度定义为比 BS1 低一个数量级"；
- **反双计数规则（= 相关性处理）**："PS4 与 PS2 不可同用"；"PP3 与 PVS1 不可同用"；"若 PVS1 满强度则不可用 PS3"；"PS3 与 PP3(SpliceAI) 不可同用"；"若变异满足 BA1/BS1 则不得用 PP1/PP4/PS4"。
- 结果：**43 个试点变异**中新旧规范比较，**93% 得到有临床意义的分类**（VUS 减少、确定性提高）。
- ⇒ 我们要抄的**不是**它的 LR 数值，而是它的三条纪律：**(a) 每条证据写死数值阈值；(b) 显式声明哪些证据互斥；(c) 用一小批试点（43 例）验证整条流水线**。

〔预印本〕**10.64898/2026.09.07.26362456**（经验校准的 AF 阈值）【摘要】：按**遗传模式 + 基因水平 missense 约束**分层池化变异，用核密度估计拟合 P/B 分布，**把阈值定在似然比跨越 ACMG/AMP 证据强度处，先验取 0.0441**；分层阈值在留出基因上 **96.7% 准确率 vs 不分层 90.1%**；限定在 73 个 ClinGen 专家面板基因时 **91.0% 准确率 @ 69.5% 变异覆盖 vs 面板自定阈值的 88.8% @ 86.2%**。⇒ **闸门阈值应随"基因/家族水平约束"分层，不能全局一个数。**

### 3.3 每个闸门该设多大 LR？——最小校准集规模〔本报告推算，输入均为标准二项分布公式〕

设某闸门的敏感度 Se、特异度 Sp，用 `n₊` 个"实验阳性"与 `n₋` 个"实验阴性"金标准样本估计。95% CI 半宽近似 `1.96·√(Se(1−Se)/n₊)`：

- 要把 **Se 估到 ±0.10**（Se≈0.8 时）→ `n₊ ≈ 1.96²×0.8×0.2/0.10² ≈ **62**`；±0.05 → **≈246**。
- 要把 **Sp 估到 ±0.10**（Sp≈0.9）→ `n₋ ≈ **35**`；±0.05 → **≈139**。
- LR⁺ = Se/(1−Sp) 的**对数**不确定度由两侧二项方差相加（delta 法）：`Var(ln LR⁺) ≈ (1−Se)/(n₊·Se) + Sp/(n₋·(1−Sp))`。若希望 **log₁₀(LR⁺) 半宽 ≤0.2（即 LR 的倍数不确定度 ≤1.6×）**，在 Se≈0.8、Sp≈0.9 时需 `n₊ ≈ n₋ ≈ **170**`（±0.1 则要 ≈670）。⇒ **单靠 40–50 例试点只能验证流程、不能标定 LR**；TP53 VCEP 的 43 例试点用于验证规范（✅ 10.1186/s13073-025-01536-3【全文】），其 LR 数值本身来自已发表的池化数据集。
- **代价对比（用于反推值不值得下单）**：✅ 10.1371/journal.pcbi.1009446【全文】给出真实漏斗：**122 条基因 → 65 条可溶（53%）→ Amplex Red 过氧化物检出活性筛查、6 种底物**。⇒ 要拿 ~100 个"真阴性+真阳性"标签，实际需送 **≥2×10²–3×10²** 个构建体；这正是"计算闸门必须先把候选砍到 ~10² 数量级"的定量依据。
- **先验从哪来**（不是拍脑袋）：✅ 10.1371/journal.pcbi.1000605【全文】：以 37 个有充分实验信息的酶家族为金标准，Swiss-Prot 多数家族错注释率**接近 0%**，而 GenBank NR / TrEMBL / KEGG 的平均错注释率跨 6 大超家族为 **5%–63%**；**37 个家族中有 10 个在至少一个数据库里错注释率 >80%**；enolase 超家族平均 22–24%、HAD >60%、crotonase >20%（TrEMBL/KEGG）。⇒ 若我们的候选只带 TrEMBL/自动注释，**先验 P(注释正确) 的量级是 0.4–0.8，而不是 0.95**；若其 Swiss-Prot  Reviewed 同类有实验条目，先验可显著提高。

### 3.4 建议的整合式（把我们现有证据块套进 LR 框架）

```
先验 P0  = f(UniProt 评审状态, 家族实验确证条目数)        # 3.3
证据块（块内合并，块间相乘；互斥关系显式声明）：
  E1 化学可行性闸门（一票否决型，不进概率）：5′-端活化/PPi 离去路径、3′-5′ vs 2′-5′ 可选性
  E2 折叠/家族（UniRule+InterPro+RetroRules 命中）        → LR 由校准集估
  E3 催化几何（M-CSA/CSA 模板 + 两金属 3.9 Å + 金属配位）  → LR
  E4 预组织系综（PLACER 式：关键接触在 n 个系综中的出现频率）→ LR  ← 与 E5 合并为"构象块"
  E5 MD 口袋/金属统计（420 ns）                            → 并入 E4，不单独相乘
  E6 序列/零样本（EVE/PLM log-odds，ProteinGym 天花板 ρ≈0.15–0.43）→ LR ≤ 小值
  E7 基因邻域/操纵子共现                                  → LR
后验 P = odds(P0) × Π LR_i → 概率；输出必带 (a) reliability/ECE 自检，(b) 弃权区间，(c) FDR（多样本时 BH）
```

## 四、阴性结论与限定范围的写法（含文献实例）

**方法学锚点**：✅ **10.1136/bmj.311.7003.485**（Altman & Bland 1995, BMJ "Absence of evidence is not evidence of absence"）——统计不显著不等于无效；正确写法是给出效应量与置信区间，说明"排除了多大的效应"。

**计算酶功能领域里可直接模仿的"限定式阴性"表述（均为原文写法）**：

1. **限定"证据类型"而非"对象"**：✅ 10.1371/journal.pcbi.1014034【全文】不说"结构比对无效"，而说"在功能差异取决于局部区域的、全局结构相似的蛋白上**假阳性率高**"。
   ⇒ 我们："**本 MD 系综中未观察到能同时满足金属 A–B 距离 ~3.9 Å 与 3′-OH→α-P 反向接近的构象**，因此该系综**不支持**在给定拓扑下成键"，而非"该蛋白无功能"。
2. **限定"底物/条件域"**：✅ 10.1093/nar/gkag864【全文】："其他 RNA 聚合酶**也显示出**从头聚合的潜能，**但需要显著更高的底物浓度且效率更低**"——阳性被限定量级，而不是被否认。
   ⇒ 我们若否，也要写"在 X–Y mM Mg²⁺、0.5–1 mM NTP、pH Z 条件下未观察到"。
3. **限定"覆盖天花板"**：✅ 10.1093/nar/gkx1012【全文】M-CSA 只覆盖 30% 四级 EC。⇒ "M-CSA/CSA 未命中该位点"不能作为阴性证据引用，因为**库本身不完备**。
4. **限定"模型适用域"**：✅ 10.1038/s41467-026-68727-3【全文】外部集（平均序列同一性 65.9%）上 F1 0.93→**0.68**，欠代表类仅 **0.42**。⇒ "工具没预测出来"必须先声明候选是否落在其适用域内。
5. **非加法/相关证据的显式承认**：✅ 10.1016/j.ajhg.2025.07.011【全文】标题即结论——"**当 2 加 4 不等于 6**"。⇒ 阴性报告里要写"本报告不把 E4/E5 当作独立证据"。
6. **必须给"能改变结论的观察"**：TP53 VCEP 的规范（✅ 10.1186/s13073-025-01536-3【全文】）为每条 code 写明"在何种数据下升级/降级"（如"若 PVS1 满强度则不得用 PS3"）。⇒ 我们的阴性结论应附：**若 X 实验出现 Y 结果，则本阴性作废**（例如"5′-三磷酸化受体寡核苷酸在 0.5 mM Mg²⁺ 下出现单核苷酸迁移条带"）。

**建议的模板（本项目可直接使用）**：
> "在本次证据范围内（固定拓扑 420 ns MD 的 N 个构象、QM/MM 界面未收敛、M-CSA/CSA/UniRule 检索、基因邻域核验），**我们没有观察到支持该位点在无模板条件下以游离底物与 ATP 形成 3′–5′ 连接成键的正向几何/化学证据**；据此我们把'能成键'的**后验判定为低（附 90% 区间）**。本结论**不等于**该蛋白无核酸转移酶活性：以下观察将推翻它——(a)…；(b)…；(c)…"

**反推（结论，〔本报告推算〕+ 上述实测）**：
- 若"送 200 条候选"实验成本可接受（合成基因 ~$70–90/条 600 bp，见同项目 `cost-benchmarks.md`），而**家族先验阳性率 ~20–50%**（TrEMBL 错注释 5–63%、可溶率 53%），那么一个"准确率 60% 的计算闸门"基本不改变期望命中数；
- **值得下单的闸门判据要求**：把后验推到一个**可被单批实验否证/证实**的区间（例如 n₊≈60、n₋≈60 的校准集能给出 log₁₀LR 的 ±0.2 精度）；
- 更实际的路径：**不要指望一个高精度闸门，而是"1.6% 通过率的强闸 + 少量高信息量实验"**（Baker 的 AF2 闸 → PLACER 闸 → 129/192 送样 → 84%/20% 分层读出）。

**未核实（本章）**：4MU 释放反应的**绝对检出限（nM/fmol）与 384 孔通量**未核到一手方法学论文；同位素计数（³²P）与非放射性法（荧光/PAD）的**成本与 LOD 对比表**未核到；c-di-AMP/c-di-GMP 的 **LC-MS/MS 定量 LOD**未核到一手原文（本轮只命中 ✅ 10.1002/bit.28112 这种工艺类文章，非 LOD 方法学）。需要的证据：分析化学期刊中"fluorogenic substrate detection limit 4-methylumbelliferone 384-well"与"cyclic dinucleotide targeted LC-MS/MS LLOQ"类论文原文表格。

## 附：可直接变成本项目闸门阈值的硬结论（带出处）

1. **PLACER 型预组织闸的通过线 = "关键接触在系综中的形成频率"，且经验通过率量级为 1.6%**（通过 AF2 结构闸〔催化残基 Cα 全部 <1.0 Å〕之后）。✅ 10.1073/pnas.2427161122 + 10.1126/science.adu2454【全文】。对我们：把"UTP-3′O···Pα(ATP) 成键几何 + 金属 A–B≈3.9 Å"作为系综判据，**报告通过频率而不是单帧距离**；预期该闸会把候选砍掉两个数量级，这是设计意图不是失败。
2. **功能预测工具不能当硬闸：非冗余测试集上最好方法 F1 也只有 0.72–0.84，DeepEC 只有 0.085–0.23，且"必输出型"工具在非酶上 FDR=1**；同时 65.9% 序列同一性就足以让 F1 从 0.93 掉到 0.68。✅ 10.1371/journal.pcbi.1014034【全文·表 2】；✅ 10.1038/s41467-026-68727-3【全文】。对我们：EC/GO 类工具只能当"证据块之一（小 LR）"，且**必须先报候选与训练集最高同一性**，<70% 时权重下调；同时任何此类闸必须配非酶阴性对照。
3. **3′–5′ 连接在无模板体系里化学上不成立，除非存在 5′-活化（5′-三磷酸端或 5′-腺苷酸化中间体）**；同时，目标产物若要连续掺入同种核苷酸，就必须有内在模板或外源模板，Thg1/TLP 全部是**模板依赖**、TENT/CCA-adding 是**无模板但靠蛋白自身内在模板**。✅ 10.1261/rna.080156.124【全文】；✅ 10.1021/acs.biochem.5c00162【全文】；✅ 10.3389/fgene.2014.00036；✅ 10.1093/nar/gkag864【全文】。对我们：这是一条**先于任何 MD/QM 的化学闸门（一票否决型）**，写法参照 Tavtigian 对 BA1 的处理——把它放在概率框架之外显式声明。
